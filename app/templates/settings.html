YouTube Authentication

Bypass YouTube's CAPTCHA by providing authentication cookies.

Option 1: Upload Cookies File

Upload a cookies.txt file exported from your browser.

OR

Option 2: Extract from Browser (local only)

Requires yt-dlp installed and browser access.

How to export cookies:

  1. Install yt-dlp
  2. Log in to YouTube in your browser
  3. Run: yt-dlp --cookies-from-browser firefox --cookies cookies.txt --no-download https://www.youtube.com
  4. Upload the generated cookies.txt file above

Docker users: Or mount your cookies file directly: -v ./cookies.txt:/app/cookies.txt:ro and set YTDLP_COOKIES_FILE=/app/cookies.txt in .env
